JUDGMENT CALLS
--------------

JC-a. [the company] is used as ONE literal token even where the surrounding article reads
      badly: "our [the company] employees" (A excerpt 8) and "follow the [the company] systems
      and procedures" (rev-09). R2 says to preserve grammar, and this trades that away on
      purpose. The reason is R2's own spec requirement: the citation-verification harness has
      to normalise the token "[the company]" before string-matching, and a normaliser that
      expands that token restores the source text exactly in both of these sentences. Variants
      ("[company]", "[the company's]") would read better and would not normalise. Matchability
      beat prettiness. If the harness spec instead defines a family of tokens, these two lines
      should be revisited.

JC-b. R5 IS NOT APPLIED INSIDE QUOTE BODIES, AND THIS LEAVES THREE PLACE NAMES IN THE PACKET.
      The brief's Rule One lists the rules permitted to edit a quote body as R2, R3, R4 and
      R6/A1. R5 is not on that list, so three in-body place strings survive:
        · rev-09 body: "The Downey location has issues with the management"
        · E excerpt 2 body: "the Mississippi Department of Employment Security"
        · E excerpt 2 body: "its Marshall County facility"
      Each is a one-query identifier. I did not extend R5 into quote bodies on my own
      initiative, per the brief's instruction not to resolve a ruleset conflict unilaterally.
      THIS NEEDS A DECISION, and it is the largest residual exposure in this packet.
      Two further points that should weigh on it:
        1. The packet is now internally inconsistent in a visible way. rev-09's attribution
           reads "[Site G]" while its quote body, one clause later, reads "Downey". A rater
           can see that a site was tokenised and then printed anyway. That is worse than
           either consistent answer.
        2. The cost of tokenising in-body is genuinely low here. "The [Site G] location has
           issues with the management" loses nothing — the claim is about a site diverging
           from company procedure, and the token preserves that it is a specific named site.
           This is not the "distinctive phrase" case the governing principle protects; a city
           name carries no dimension signal.
      Recommended amendment: add R5 to Rule One's in-body permitted list, restricted to place
      names that already have a token assigned in the Section 4 pre-flag block, so the edit
      stays mechanical. If instead the decision is to leave them, say so explicitly in the
      ruleset, because the current text reads as an oversight rather than a choice.
